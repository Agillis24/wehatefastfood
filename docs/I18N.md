# I18N.md

Two tiers, one prompt, one hard rule: **a locale is offered only when a catalogue exists.** An English page under a foreign flag is worse than not offering the language.

---

## Locale is not market

|          | What it is                              | Where it lives          |
| -------- | --------------------------------------- | ----------------------- |
| `locale` | the language of the prose               | path segment: `/cs/...` |
| `market` | the jurisdiction the _figures_ describe | path segment: `.../GB`  |

They are independent. A Czech speaker may legitimately want UK figures. Both are in the URL so a shared link shows the recipient exactly what the sender saw.

---

## Tier 1: reviewed, committed, indexed

Source is `en`. `npm run i18n:translate -- --locale=cs` sends each namespace to the Anthropic API with `content/glossary.json` injected, and writes the result into `packages/i18n/messages/<locale>/`. Output is committed, so translations are diffable and reviewable and cost nothing at request time.

**A translation is rejected, not shipped, when:**

- the returned JSON does not parse;
- its key set differs from the source in any way;
- any ICU placeholder is renamed, added or dropped.

Strict on purpose. A dropped key is a blank on a page and a renamed placeholder throws at render, and neither is visible to anyone who cannot read the target language — which is exactly our situation.

`cs` is the **pilot**: the one locale the client can personally review. It runs first and alone, and it is the acceptance test for the pipeline before a token is spent on the other seven.

Each locale carries `_provenance.json` with `reviewedByHuman`. It stays `false` until a human who reads that language actually has.

---

## Tier 2: on demand, narrowed, noindex

`POST /api/translate` with `{ locale, namespace, contentHash }`.

**Scope is narrowed on purpose.** Interface strings and factual fields only. `evidenceSummary`, `notableDivergence`, `ourTake` and `longIntro` are stripped before the model sees them (`TIER2_FORBIDDEN_FIELDS`) and stay English behind a visible notice. Machine-translating a claim about food safety into a language nobody here reads is a claim we cannot stand behind and cannot audit.

Tier-2 responses carry `noindex`, and tier-2 locales are absent from the sitemap. A thin unreviewed rendering must never compete in search with the reviewed one.

**Abuse control**, because this is an unauthenticated POST that spends money:

1. the `(namespace, contentHash)` pair must appear in the build-time manifest, so only text we shipped can reach the model;
2. the locale must match a conservative pattern;
3. per-IP rate limit.

Cached under `t:{locale}:{namespace}:{contentHash}` with no expiry. Permanent is only safe because the hash changes when the English does. Validated for key set and placeholders **before** caching — a bad translation written once would otherwise be served for ever.

Upstash when configured, in-memory LRU otherwise, so the app runs with zero external services.

## Rules that bite

**Never interpolate a noun into a sentence.** Czech proved it on day one: `"contains {value} of {nutrient}"` renders as _"obsahuje 9 g cukr"_, where the genitive _"cukru"_ is required. Give each case its own complete message.

**Pass counts to ICU as numbers, not preformatted strings**, or no plural category can be selected. Czech needs `many` for decimals — that is what makes _"2,25 kostky"_ correct and _"2,25 kostek"_ wrong.

**Zero hard-coded user-facing strings.** `react/jsx-no-literals` is an error in `app/` and `components/`.

**Numbers, dates and units go through `Intl`.** A decimal comma is not cosmetic.

**RTL** works through CSS logical properties; `dir` is set from the locale. `ar` reaches the site through tier 2 only.

---

## Checking

`npm run i18n:extract` regenerates the manifest and reports, per locale: missing keys, orphaned keys, and placeholder mismatches. It is a gate in `npm run check`.

Its placeholder extractor is a brace-depth scanner, not a regex, because ICU is not a regular language: in `{count, plural, =0 {No entries match} other {# entries}}` the token `{No entries match}` is a branch body spelled exactly like an argument. Two regex versions produced false positives that would have rejected every correct translation. Tests pin it.
